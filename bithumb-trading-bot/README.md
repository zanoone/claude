# Bithumb 거래량 기반 단타 트레이딩 봇

Bithumb API 2.0 (JWT)과 WebSocket을 활용한 거래량 기반 자동매매 단타 솔루션

## ⚠️ 중요 경고

- **실제 자금이 투입되는 프로그램입니다**
- 암호화폐 거래는 높은 위험을 수반합니다
- 모든 투자 손실은 본인 책임입니다
- **반드시 테스트 모드로 충분히 테스트 후 사용하세요**

## 📋 주요 기능

### 1. 실시간 데이터 분석
- WebSocket을 통한 실시간 시세/체결 데이터 수신
- 거래량 급등 감지 및 모니터링
- 모든 상장 코인 동시 모니터링

### 2. 거래 전략
- **거래량 기반 코인 선택**: 거래량이 급등하는 코인 자동 탐지
- **한 번에 한 코인**: 전액 매수/매도로 단타 효율 극대화
- **빠른 진입/청산**: 거래량 모멘텀 기반 진입, 목표 수익률 도달 시 즉시 청산

### 3. 안전장치
- **익절**: 목표 수익률 도달 시 자동 매도 (기본 2.0%)
- **손절**: 손실 한도 도달 시 자동 매도 (기본 -1.5%)
- **일일 최대 손실 제한**: 일일 손실률 5% 도달 시 거래 중지
- **수수료 고려**: 매수/매도 각 0.25% 수수료 자동 계산

### 4. 블랙리스트
- 변동성이 낮거나 거래하고 싶지 않은 코인 제외
- 기본: BTC, ETH, USDT, USDC, DAI, BUSD, TUSD, XRP, ADA, SOL, DOT, PENGU, DOGE

## 🚀 설치 및 실행

### 1. 의존성 설치

```bash
cd bithumb-trading-bot
pip install -r requirements.txt
```

### 2. 환경 설정

`.env` 파일을 수정하여 API 키와 전략 설정:

```bash
# API 키 설정 (필수)
BITHUMB_API_KEY=your_api_key_here
BITHUMB_SECRET_KEY=your_secret_key_here

# 거래 전략 설정
FEE_RATE=0.0025              # 수수료 (0.25%)
MIN_PROFIT_RATE=0.006        # 최소 수익률 (0.6%)
STOP_LOSS_RATE=0.015         # 손절 (-1.5%)
TAKE_PROFIT_RATE=0.02        # 익절 (2.0%)
MAX_POSITION_RATIO=0.95      # 최대 포지션 비율 (95%)

# 거래량 분석
MIN_VOLUME_KRW=50000000      # 최소 거래량 (5천만원)
VOLUME_SPIKE_THRESHOLD=2.0   # 거래량 급등 임계값 (2배)

# 안전 설정
MAX_DAILY_LOSS=0.05          # 일일 최대 손실 (5%)
DRY_RUN=true                 # 테스트 모드 (true/false)
```

### 3. 실행

#### 테스트 모드 (시뮬레이션)
```bash
# .env에서 DRY_RUN=true 설정
python trading_bot.py
```

#### 실제 거래 모드
```bash
# .env에서 DRY_RUN=false 설정
# 주의: 실제 거래가 실행됩니다!
python trading_bot.py
```

### 4. 종료

`Ctrl+C`를 누르면 안전하게 종료됩니다.
- 보유 중인 포지션은 자동으로 청산됩니다
- 거래 통계가 출력됩니다

## 📊 트레이딩 로직

### 진입 조건
1. 거래량이 평균 대비 2배 이상 급등
2. 최소 거래대금 5천만원 이상
3. 블랙리스트에 없는 코인
4. 현재 포지션 없음

### 청산 조건
1. **익절**: 수익률 +2.0% 도달
2. **손절**: 손실률 -1.5% 도달
3. **시간 기반**: 5분 이상 보유 + 최소 수익률 0.6% 이상
4. **거래량 감소**: 거래량 급등이 끝나고 수익 상태

### 수수료 계산
- 매수 수수료: 0.25%
- 매도 수수료: 0.25%
- **총 수수료: 0.5%**
- 최소 목표 수익률 0.6%로 설정하여 수수료 커버

## 🔧 API 키 발급

1. [Bithumb](https://www.bithumb.com) 로그인
2. 마이페이지 > API 관리
3. API 2.0 (JWT 방식) 선택
4. 권한 설정:
   - 자산 조회
   - 주문 조회
   - 주문 하기
   - 출금 주소 조회
5. API 키 복사하여 `.env`에 입력

## 📞 문제 해결

### API 인증 실패
- API 키가 올바른지 확인
- API 2.0 (JWT 방식) 사용 확인
- API 권한 설정 확인

### WebSocket 연결 실패
- 인터넷 연결 확인
- 방화벽 설정 확인
- Bithumb 서버 상태 확인

### 거래 실행 실패
- 잔고 부족 확인
- 최소 거래 금액 확인 (5,000원)
- API 일일 호출 한도 확인
